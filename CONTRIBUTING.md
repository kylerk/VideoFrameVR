# Contributing

Bug reports, feature requests and pull requests are welcome. Use the issue forms;
blank issues are off.

## AI use must be disclosed

Human-written issues and pull requests are preferred. If AI wrote or
rewrote any part of yours, code or text, say so and name the model and the harness
(for example "Claude Opus 5.5 in OpenCode"). Issues and pull requests that
hide AI use, or that look like unreviewed AI output, are closed without review.

## Pull requests

- Open an issue first for anything larger than a small fix, so we can agree on it.
- Keep a pull request to one change, and say how you tested it: which device and
  what video.
- Building: see [BUILDING.md](BUILDING.md).
